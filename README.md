# Animal Multiclass CNN

Training and evaluation pipeline for classifying wildlife images into multiple species using a convolutional neural network. Includes data preprocessing, model architecture (MobileNet3-small), training loops with loss/accuracy tracking, and visualization of results.

## Getting Started

Clone the repository and install dependencies from requirements.txt:

```bash
git clone https://github.com/IncreasingLoss/animal_multiclass_cnn.git
cd animal-multiclass-cnn
pip install -r requirements.txt
```

Run training with `python Wildlife_Animal_Classifier/app.py` and view results in the `trainingpics/` directory.# animal_multiclass_cnn
